УПРАЖНЕНИЕ «ЧЕМПИОНАТ»

Что сделано:
1. Реализованы классы Player, Position, TeamGoals.
2. Реализован интерфейс IResolver и его реализация PlayerResolver.
3. Данные прочитаны из fakePlayers.csv в список Player.
4. Все 8 пунктов Задания 1 реализованы с использованием Stream API.
5. Реализованы все 4 варианта графика. При запуске программа выбирает нужный вариант по формуле N % 4 + 1.
6. Для графиков используется JFreeChart.

Запуск:
1. Установить JDK 21 и IntelliJ IDEA.
2. Открыть папку проекта Championship_Stream_Homework как Maven-проект.
3. Дождаться загрузки зависимости JFreeChart.
4. Открыть src/main/java/ru/championship/Main.java.
5. Запустить Main.
6. Ввести свой номер N в списке группы. Программа рассчитает вариант и откроет график.

Файл fakePlayers.csv уже находится в src/main/resources.

Важно:
- Пустое поле Agency считается отсутствием агентства.
- В задании 7 агентства сравниваются по сумме трансферной стоимости всех их игроков; строки без агентства не образуют агентство.
- Вариант графика выбирается строго по формуле из задания: N % 4 + 1.
